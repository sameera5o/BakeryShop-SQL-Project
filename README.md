# BakeryShop – SQL Data Analysis Project

## Project Overview
BakeryShop is a SQL database project designed for a bakery and café business. It demonstrates database creation, data management, and sales data analysis using SQL Server.

## Project Objectives
- Design and organize a relational database.
- Manage products, customers, and orders.
- Analyze sales data and business performance.
- Practice SQL queries to answer business questions.

## Database Structure
The database consists of four main tables:

- **Products:** Stores bakery and café product information.
- **Customers:** Stores customer information.
- **Orders:** Stores customer order information.
- **OrderDetails:** Stores products and quantities within each order.

## SQL Skills Demonstrated
- Database and table management
- Primary Keys and Foreign Keys
- Data insertion and modification
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate functions (COUNT, SUM, AVG, MAX)
- JOIN operations
- UNION ALL
- Data validation and sales analysis

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Project Data
- 100 products
- 20 customers
- 65 bakery products
- 35 café products

## Project Purpose
This project was developed as part of my learning journey in SQL and data analytics, with a focus on database design and practical business analysis.
